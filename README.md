# AsteRAGE II - Remastered!

## ChangeLog
### Patch 1.1.0

#### Fixes:
- Fixed a bug that would cause images to not load correctly on linux specifically.
- Fixed a bug that caused the frame rate to stutter on the splash screen.
- Increased efficiency of game loop by removing unnecessary repeat iterations over objects in play.
- Increased height of game board in both games to more closely approximate the screen dimensions of a classic arcade game.
- Significantly overhauled codebase to reflect lessons learned on code quality.
